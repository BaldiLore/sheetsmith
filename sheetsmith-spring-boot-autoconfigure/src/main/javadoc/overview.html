This module integrates sheetsmith, the annotation-driven Excel generator built on Apache POI, with Spring Boot 4. With it on the classpath, usually through the sheetsmith starter, a {@code Sheetsmith} bean is available without any configuration. The bean is configured from the {@code sheetsmith.*} properties, uses every {@code CellConverter} bean of the application as an application converter, and creates field converters through the application context. Optionally, the sheet classes of given packages are validated at startup.

Example

@Service
public class CustomerExport {

    private final Sheetsmith sheetsmith;

    public CustomerExport(Sheetsmith sheetsmith) {
        this.sheetsmith = sheetsmith;
    }

    public byte[] export(List<CustomerRow> customers) {
        return sheetsmith.generate(List.of(SheetData.of("Customers", CustomerRow.class, customers)));
    }
}

Packages

  • {@link cloud.baldilorenzo.sheetsmith.autoconfigure}: the auto-configuration, the configuration properties, the Spring converter factory and the startup validator.

Maven coordinates

Applications depend on the starter, which brings this module, the sheetsmith core and Spring Boot: 

<dependency>
    <groupId>cloud.baldilorenzo</groupId>
    <artifactId>sheetsmith-spring-boot-starter</artifactId>
    <version>${sheetsmith.version}</version>
</dependency>

Replace {@code ${sheetsmith.version}} with the version of this documentation. This module itself is published as {@code cloud.baldilorenzo:sheetsmith-spring-boot-autoconfigure}.
